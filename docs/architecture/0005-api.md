# Local API POC
Apply infrastructure/migrations/001_projects.sql to the development PostgreSQL database. In backend/api run npm install, set DATABASE_URL and run npm start. The server binds only to loopback. No authentication, TLS, browser integration or production deployment is provided.
GET /api/projects lists projects; GET /api/projects/:id retrieves a snapshot; PUT /api/projects/:id accepts {project,revision}. Revision 0 creates, later revisions use atomic conditional updates. Stale writes return 409. Run node --test tests/*.test.mjs from repository root. The HTTP test uses the in-memory store; PostgreSQL integration tests remain necessary.
